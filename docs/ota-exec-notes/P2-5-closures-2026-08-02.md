## 3. 关键设计（三元语义）

`ota_backup_info_t` 增加 `ota_backup_commit_state_t commit_state`：
`OTA_BACKUP_COMMIT_NONE / VERIFIED_STAGED / VERIFIED_CONFIRMED / UNKNOWN`。
`ota_backup_stage` 提交后：任何 `bcb_commit` 非 OK 均 re-arbiter 分类，不再假定
CONFIRMED；unknown 时返回 `OTA_BACKUP_ERR_COMMIT_AMBIGUOUS`，Session 映射到
`OTA_SD_ERR_COMMIT_UNKNOWN` 避免覆盖 candidate/backup。
