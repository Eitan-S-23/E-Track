# Local Source Preservation, 2026-11-25

This branch is an archival snapshot before any later disk cleanup, not a new
product release, completed acceptance or integration into main. Main remains
the authoritative product branch. No cleanup is performed by this upload.

Selected previously untracked tools, tests and documents, plus pending historical
documentation, are preserved at their original paths. The accompanying manifest
records exact snapshot SHA-256/Git blob identities, original parse-check outcomes
and exclusions. Original source bytes are not corrected or reformatted just to
make a historical snapshot appear tested. Do not execute old hardware, deployment
or collection tools merely to verify that the backup exists.

The concurrently edited MCU source, firmware version and matching Dialplate tests
are deliberately excluded. The archive keeps their versions from its recorded
main parent. The primary checkout, main ref and shared index are not switched or
written by this archival operation. Planning records are historical snapshots,
not proof that concurrent MCU work has completed.

Caches, repeated installers, large historical ZIPs and any source flagged for
sensitive-content review are not uploaded. They remain untouched locally. Ignored
caches and historical worktrees need a separate preservation review before any
deletion; this manifest is not permission to delete the whole repository.

To recover a preserved file, clone/fetch this repository, inspect this archive
branch and its manifest, then restore the selected path into a new task based on
current main. Fetching the branch does not deploy firmware, an App or Cloudflare.
Credentials and signing inputs remain in their existing protected routes, not
ordinary source-control files.

## Address-Safe Supplement

All 29 previously held address-bearing files are now included as sanitized
archival copies. Consistent synthetic addresses replace the original device
addresses. Original local files remain untouched. Historical large archives
and unique ignored-directory material are being preserved as separate GitHub
backup attachments, not production releases or acceptance evidence.
