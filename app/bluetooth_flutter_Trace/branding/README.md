# E-Track App Icon

The source is the user's selected final "route E" variant, formerly
`generated-images/29.png`. It is preserved byte-for-byte as `e_track_source.png`.
Its SHA-256 is `fa849d68e0d718a08d8461f2e04caecb6807d1396090ad64201f2a88b0d4cf85`.
This folder is a design input, not a Flutter runtime asset bundle.

From the implementation worktree root, with Pillow available:

    python -B Tools/assets/app_icons.py --repo-root .
    python -B Tools/assets/app_icons.py --repo-root . --check

The generator checks all output paths before writes, derives Android density and
adaptive layers, existing iOS AppIcon entries and a multi-size Windows ICO.
`icons.json` binds the actual generated bytes and renderer version. The local
preview is regenerable. `ic_stat_e_track.xml` is the separate white notification
silhouette; never use the colorful launcher raster as a status-bar small icon.
No package ID, signing, label, version or update channel is changed by this work.
